コメントを受け取る「わんコメ」とまだつながっていません。

  1. わんコメの公式サイト（onecomme.com）の「ダウンロード」から、自分の PC 用（Windows または macOS）を入れます。
  2. わんコメを起動します。
  3. 丸ストの上級の細かさで「接続端末」を開き、「わんコメをつなぐ」を押します。出たコードを、わんコメ側の丸ストの連携の設定画面に入れます。
  4. つながると、わんコメのコメントがここに流れ、この案内は消えます。

公式サイト: https://onecomme.com/（ダウンロードは https://onecomme.com/download）。くわしくは、上のメニュー「ヘルプ → わんコメの入れ方」。
